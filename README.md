# Zill OCR Overlay

Android에서 PPSSPP로 실행하는 **Zill O’ll Infinite Plus 일본어판**의 지정 화면 영역을 실시간 OCR하고, 인식된 일본어를 한국어로 번역해 게임 화면 위에 표시하는 프로젝트입니다.

현재 개발 버전은 **0.4.0-alpha1 · 로컬 GGUF 모델 구동 벤치마크**입니다.

## 현재 구현 상태

- MediaProjection + PPSSPP 지정 ROI 캡처
- Google ML Kit 일본어 OCR, 500ms 주기
- 2회 안정화 및 유사 문장 중복 억제
- OpenRouter API 번역
- Room 영구 번역 캐시 + 메모리 LRU 캐시
- 사용자 편집 용어집 및 번역 기록
- **Android용 llama.cpp 사전 빌드 AAR 추가**
- **GGUF 모델 파일 선택 및 앱 전용 모델 폴더 복사**
- **로컬 모델 단독 일본어→한국어 테스트 번역**
- 로컬 테스트에서 총 소요시간 및 생성 속도(tok/s) 표시
- 기본 로컬 벤치 설정: context 1024, CPU threads 4, 출력 최대 128 tokens

## 0.4.0-alpha1 목적

이번 알파는 로컬 모델을 곧바로 PPSSPP 실시간 파이프라인에 연결하지 않습니다. 먼저 POCO X8 Pro Max에서 TranslateGemma 4B Q4_K_M 같은 GGUF가 실제로 로딩되고, 일본어→한국어 번역 속도와 메모리 부담이 실사용 가능한지 확인합니다.

```text
GGUF 파일 선택
  ↓
앱 모델 폴더로 복사
  ↓
llama.cpp CPU/NEON 로딩
  ↓
테스트 일본어 번역
  ↓
번역문 + 총 시간 + tok/s 측정
```

벤치마크가 통과하면 다음 알파에서 모델을 한 번만 로드한 채 유지하는 `LocalTranslationProvider`를 만들어 기존 실시간 OCR 파이프라인에 연결합니다.

## 로컬 모델 테스트 방법

0.4.0-alpha APK를 설치하면 임시로 런처에 `질올 로컬 모델 테스트` 아이콘이 추가됩니다.

1. TranslateGemma 4B Q4_K_M 등 `.gguf` 모델을 폰에 다운로드합니다.
2. `질올 로컬 모델 테스트`를 실행합니다.
3. `GGUF 모델 파일 선택`을 누르고 다운로드한 모델을 선택합니다.
4. 모델이 앱 전용 저장공간으로 복사될 때까지 기다립니다.
5. 기본 테스트 문장 또는 원하는 일본어 대사를 넣고 `로컬 모델 테스트 번역`을 누릅니다.
6. 번역 결과, 총 시간, tok/s를 기록합니다.

2.5GB 안팎 모델을 복사하므로 테스트 시 다운로드 원본과 앱 내부 복사본을 합쳐 일시적으로 약 5GB 이상의 여유 저장공간을 권장합니다. 복사가 끝난 뒤 다운로드 폴더의 원본은 삭제해도 앱 내부 복사본은 유지됩니다.

## 기존 API 번역

기존 `질올 OCR 오버레이` 아이콘은 그대로 유지됩니다. OpenRouter API 번역, Room 캐시, 용어집 기능은 0.3.x와 동일하게 사용할 수 있습니다. 로컬 벤치 실패 시에도 기존 API 경로에는 영향을 주지 않도록 분리했습니다.

## 기본 용어집

- `ロストール → 로스토르`
- `ソウル → 소울`
- `インフィニティア → 인피니티아`

## 알려진 한계

- 0.4.0-alpha1의 로컬 모델은 **단독 벤치마크용**이며 아직 PPSSPP 실시간 번역에는 연결되지 않았습니다.
- 로컬 테스트는 현재 매 테스트마다 모델을 로드한 뒤 해제하므로 실제 최종 구조보다 초기 지연이 큽니다.
- llama.cpp AAR은 현재 CPU/NEON 실행이며 Vulkan/NPU 가속은 아직 사용하지 않습니다.
- 4B Q4 모델이 PPSSPP와 동시에 충분히 빠른지는 반드시 실기기 측정이 필요합니다.
- 화면 회전 중 VirtualDisplay 재구성, OCR 전체화면 임시 Bitmap 제거는 후속 최적화 대상입니다.
