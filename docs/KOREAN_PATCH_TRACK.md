# Zill O'll Infinite Plus Korean Patch Track

이 문서는 기존 Android OCR 오버레이와 별도로, **PSP판 Zill O'll Infinite Plus 자체 한글패치 제작 가능성**을 조사하고 구현하는 작업 트랙을 정리한다.

## 목표

- 기존 영문패치/역공학 성과를 최대한 재사용한다.
- 일본어 원본 ISO에 한국어 텍스트·폰트·그래픽을 직접 삽입하는 경로를 우선 검토한다.
- OCR 오버레이 프로젝트에서 축적한 용어집, 화자/문맥 규칙, 번역 캐시와 검수 데이터를 스크립트 번역 자산으로 재사용한다.
- 최종적으로 PPSSPP와 실기 PSP에서 별도 번역 오버레이 없이 구동되는 한국어판을 목표로 한다.

## 확인된 선행 사례

### 1. Muguster / Mugi PSP 영문화 프로젝트

- 2017년 실제 영어 구동 영상이 공개됨.
- 설명상 게임 엔진과 번역 스크립트에 상당한 작업이 들어갔으며, 핵심 패치는 동작 상태였음.
- 실제 PSP 하드웨어 호환을 명시.
- 그래픽 교체와 PS2 고해상도 텍스처 이식까지 수행된 사례가 있음.

참고:
- https://www.youtube.com/watch?v=tdRJYvlErbo
- https://www.youtube.com/watch?v=NhbevNPUobk
- 과거 alpha/menu patch 흔적: http://mce.do.am/project/zill/zillalpha.rar
- 과거 프로젝트 논의: https://gbatemp.net/threads/zill-oll-infinite-plus.445627/

### 2. 2026년 PSP 영문패치 공개 흔적

- 2026-08-11 기준 커뮤니티에 PSP판 영문 번역패치 실사용 게시물이 올라옴.
- 제작자명으로 `HK47196`가 언급됨.
- 캐릭터 생성 이름의 선행 `P`, 커서 정렬, 일부 1문자 폭/줄바꿈 문제 등은 남아 있으나 번역 자체는 높은 완성도로 평가됨.
- 댓글에 "official github or the author"에 버그를 보고하라는 언급이 있어 현재 프로젝트 GitHub가 존재할 가능성이 있음.

참고:

### 3. 기존 영문 스크립트 자산

- `Zill O'll Translations`에 PSP판 이벤트/엔딩 번역 스크립트가 장기간 축적됨.
- PS2판 `Zill O'll Infinite`에는 완성된 영문화 패치가 존재하므로, 공통 이벤트/용어의 교차 참조 소스로 활용 가능.

참고:
- https://zilloll.tumblr.com/

## 현재 판단

기술 리스크의 핵심은 더 이상 "PSP판에서 대사를 뽑아 다시 넣을 수 있는가" 자체가 아니다. 선행 사례로 보아 다음 항목은 이미 최소 한 차례 해결되었을 가능성이 높다.

- PSP 게임 데이터 수정 및 재패킹
- 대사 스크립트 추출/삽입
- 영문 폰트 또는 문자 렌더링 개조
- 그래픽 리소스 교체
- 실제 PSP 구동

따라서 한글패치에서는 기존 영문패치의 도구/포맷을 확보하는 것이 최우선이다.

## 우선 조사 순서

1. 2026년 HK47196 패치의 공식 배포 페이지와 GitHub 저장소 식별
2. 패치 파일이 IPS/xdelta 계열인지, 별도 빌드 스크립트/packer를 포함하는지 확인
3. Mugi 프로젝트의 과거 tool/source/archive 확보
4. PSP ISO 내부 파일 목록과 스크립트/폰트 후보 파일 식별
5. 문자 인코딩 및 glyph table 확인
6. 문자열 포인터/길이/줄바꿈 처리 구조 확인
7. 한글 glyph 삽입 최소 PoC 제작
8. 한 문장 또는 메뉴 한 항목을 한국어로 직접 출력하는 PoC 검증
9. 스크립트 일괄 추출/삽입 툴 정리
10. 기존 OCR 번역 프로젝트의 용어집/override/확정 번역 DB를 한글패치용 스크립트에 연결

## 첫 번째 PoC 성공 기준

아래 중 하나를 달성하면 본격 제작 단계로 전환한다.

- 게임 내 일본어 대사 한 줄을 한국어 한 줄로 직접 치환하여 PPSSPP에서 정상 출력
- 또는 메뉴 항목 1개를 한국어로 표시하고 저장/재실행 후에도 정상 유지

추가 확인 항목:

- 한글 완성형 최소 필요 글리프 수
- 고정폭/가변폭 여부
- 글자별 width table 존재 여부
- 줄당 최대 글자 수
- 자동 줄바꿈/수동 제어코드
- 이름 입력 화면 별도 문자표 처리 여부
- 폰트 텍스처 형식과 팔레트/비트수

## 사용자에게 필요한 자료

공개 자료만으로 포맷 분석이 끝나지 않을 경우 아래를 요청한다.

1. 사용자가 소유한 일본판 `Zill O'll Infinite Plus`의 **원본 ISO**
2. 확보 가능한 경우 **2026년 영문패치 파일 자체**
3. 이미 패치된 영문판 ISO가 있다면, 원본과 비교 분석용으로 해당 패치 결과물 또는 패치 적용 정보

원본 ISO 자체는 저장소에 커밋하지 않는다. 로컬 분석용으로만 사용하고, 결과물은 스크립트/도구/패치 파일 형태로 관리한다.

## OCR 오버레이와의 관계

기존 `ZillOcrOverlay`는 당장 폐기하지 않는다. 한글패치 제작 과정에서 다음 용도로 재사용 가치가 있다.

- 일본어 원문과 실제 화면 대조
- 번역 초벌 및 표현 비교
- 인물/지명/고유명사 용어집
- 화자별 말투 및 sticky speaker 정보
- 사용자 override와 검수 완료 번역
- 미번역/누락 이벤트 탐지 보조

다만 장기 우선순위는 **실시간 OCR 번역 고도화보다 자체 한글패치 PoC**에 둔다.

## 작업 원칙

- 제로베이스 역공학 전에 기존 영문패치 도구와 소스를 최대한 추적한다.
- 영문패치를 그대로 재배포하지 않고, 한글화에 필요한 포맷/도구/패치 절차를 분리한다.
- 게임 원본 데이터나 ISO를 GitHub 저장소에 포함하지 않는다.
- 가능한 경우 원본 일본어 스크립트를 기준으로 번역하고, 기존 영어 번역은 교차 검수용으로 사용한다.
